# TCC — Análise de Evasão Escolar

Projeto desenvolvido para o Trabalho de Conclusão de Curso em Ciência de Dados.

## Objetivo

Analisar fatores associados ao risco de evasão escolar e desenvolver um modelo preditivo para apoiar ações de Busca Ativa Escolar.

O projeto também contará com um dashboard para visualização e análise dos resultados.

## Tecnologias

* Python
* Django
* PostgreSQL
* Pandas
* Scikit-learn
* HTML, CSS e JavaScript
* Chart.js

## Estrutura

```text
tcc-evasao/
├── backend/     # Aplicação Django e modelo preditivo
├── dataset/     # Base de dados utilizada no projeto
└── README.md
```

## Dados

A base utilizada é o dataset sintético de evasão escolar disponível no Kaggle:

**Evasão Escolar Sintético — Danilo Naves**

Os dados são utilizados exclusivamente para fins acadêmicos.
